# setup
-  cài extension `jupyter` trong vscode → cho phép vscode chạy notebook `.ipynb` → loại nếu chỉ mở file mà không chạy cell
## cài `dotnet interactive` để chạy c#
-  chạy `dotnet tool install --global Microsoft.dotnet-interactive`
-  restart vscode → kernel c# xuất hiện
→ loại nếu không cần chạy c# notebook
