# .net interactive notebook trong vscode

## mục tiêu

- test nhanh snippet c#
- không cần build project
- hỗ trợ nuget package
- chạy code theo cell
- dùng làm playground kỹ thuật

---

## khi nên dùng

- spike logic / thuật toán
- test api / thư viện mới
- parse / transform data thử nghiệm
- ghi chú kỹ thuật có executable code

---

## khi nên loại

- debug production runtime
- integration test
- benchmark performance chuẩn
- build pipeline

---

## yêu cầu môi trường

- cài `.net sdk`
- cài `vscode`
- cài extension `.net interactive`

---

## cài đặt

### cài .net sdk

- tải: https://dotnet.microsoft.com/download
- kiểm tra:

```bash
dotnet --version
```

---

### cài vscode

* tải: [https://code.visualstudio.com](https://code.visualstudio.com)

---

### cài extension notebook

* mở vscode
* extensions → tìm ".net interactive"
* install extension microsoft

---

## tạo notebook

### tạo file

* tạo file:

```
playground.dib
```

hoặc

```
playground.ipynb
```

---

### chọn kernel

* chọn `.net interactive`
* chọn `c#`

---

## hello world

```csharp
Console.WriteLine("hello world notebook");
```

---

## import nuget

```csharp
#r "nuget: Newtonsoft.Json, 13.0.3"
```

---

## test package

```csharp
using Newtonsoft.Json;

var obj = new { name = "huy" };

Console.WriteLine(JsonConvert.SerializeObject(obj));
```

---

## dùng state giữa các cell

### cell 1

```csharp
var number = 10;
```

### cell 2

```csharp
Console.WriteLine(number + 5);
```

---

## reset state

* restart kernel khi:

  * biến bị sai
  * notebook chạy chậm
  * nuget lỗi

---

## workflow khuyến nghị

* test logic trong notebook
* xác nhận output đúng
* copy sang project thật
* viết unit test sau

---

## tối ưu tốc độ

* gom `#r nuget` vào cell đầu
* hạn chế import package lớn
* restart kernel khi notebook chạy lâu

---

## template notebook chuẩn

```csharp
#r "nuget: Newtonsoft.Json, 13.0.3"

using System;
using Newtonsoft.Json;

Console.WriteLine("ready playground");
```

---

## lỗi thường gặp

### vscode không thấy kernel

* restart vscode

### nuget load chậm

* kiểm tra mạng
* restart kernel

### notebook treo state

* restart kernel
