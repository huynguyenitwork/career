# biến thể 3 - business complexity engineer 
đây là cái **đáng tiền nhất**.
ít người định vị kiểu này.
## headline
```
senior software engineer
business complexity specialist
```
## summary
không bán framework.
bán khả năng giải quyết vấn đề.
ví dụ
```
chuyên chuyển hóa quy trình nghiệp vụ phức tạp thành hệ thống phần mềm ổn định, dễ mở rộng và có khả năng vận hành lâu dài.
kinh nghiệm trong f&b, manufacturing, erp, pos, finance.
```
## skill
không chia theo ngôn ngữ.
chia theo năng lực.
```
business modeling/system integration/architecture/reliability/workflow/backend engineering/database design/api design
```
framework xuống cuối.
## kinh nghiệm
không mô tả theo task.
mỗi dự án trả lời
```
business problem -> solution -> impact
vấn đề kinh doanh -> giải pháp -> tác động
```
ví dụ dcorp hiện tại có thể trình bày thành
```
problem -> solution -> impact
(pos, sap, e-commerce, không đồng bộ) -> (solution, retry, queue, idempotency, validation, monitoring) -> (impact, giảm thời gian debug, đảm bảo dữ liệu nhất quán, audit dễ hơn)
